# Demo script (target: 2:30)

## 0:00–0:20 — Problem

- **Screen:** Neutral desktop and a generic practice session; no game footage.
- **Action:** Briefly switch between a plain note and the practice window.
- **English:** “Repeated practice works best when the next action stays visible. Reopening notes between attempts breaks focus, and the small correction I wanted to remember is easy to lose.”
- **日本語訳:** 「反復練習では次の行動が見えていることが大切です。試行のたびにメモを開くと集中が切れ、覚えておきたい小さな修正を忘れがちです。」
- **Note:** Hide usernames, paths, notifications, and proprietary content.

## 0:20–0:40 — Introduction

- **Screen:** LoopNote main screen with generic demo notes.
- **Action:** Point to notes, review, and overlay sections.
- **English:** “LoopNote is a local Windows desktop practice companion. It turns structured drills into a persistent overlay and a lightweight review loop—without an account, API key, or telemetry.”
- **日本語訳:** 「LoopNoteはWindows向けのローカル練習支援ツールです。構造化した課題を常駐表示と軽量な復習サイクルに変えます。アカウント、APIキー、テレメトリは不要です。」

## 0:40–1:40 — Main workflow

- **Screen/action:** Create “Reaction practice,” save it, select it with a second note, show the overlay, drag/resize it, change opacity, toggle with `Ctrl+Alt+M`, then record a review result and download a backup.
- **English:** “I save a short drill, choose the notes that matter now, and apply them to the overlay. The cards stay readable above a window, can be moved to another monitor, resized, made transparent, or made click-through. Hotkeys keep recovery simple. After practice I record the outcome; LoopNote updates proficiency and the next review date. A local ZIP backs up the database and settings.”
- **日本語訳:** 「短い課題を保存し、今必要なメモを選んで常駐表示します。カードは他の画面より前で読め、別モニターへの移動、サイズ、透明度、クリック透過を調整できます。ホットキーですぐ復帰できます。練習後に結果を記録すると、習熟度と次回復習日が更新されます。DBと設定はローカルZIPへ保存できます。」
- **Note:** Do not restore the live database during filming.

I verified the behavior and kept final product decisions human-owned.”

- **English:** “LoopNote keeps the next repetition in sight and the practice loop moving. It is private, local, and designed to turn intention into consistent action.”
- **日本語訳:** 「LoopNoteは次の反復を見える状態にし、練習の流れを止めません。プライベートでローカル、意図を継続的な行動へ変えるためのツールです。」
