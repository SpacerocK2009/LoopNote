# SF6 Strategy Board

Windows 11で動作する、ストリートファイター6の戦略メモ・画像生成プロンプト・壁紙・サブディスプレイ常駐メモをまとめて管理するローカルWebアプリです。OpenAI APIは使用せず、ChatGPT Web版はユーザーが手動で操作します。

## 必要環境

- Windows 11
- Python 3.11以上（Python Launcher `py` を含む構成を推奨）
- インターネット接続（初回の依存ライブラリ導入とChatGPT利用時のみ）

使用ライブラリは FastAPI、Uvicorn、Pillow、python-multipart、pystray、screeninfoです。常駐メモはPython標準のTkinterとWindows APIを使用します。テスト用にpytestとhttpxを含み、データベースはPython標準のSQLiteを使用します。

## セットアップと起動

1. `start.bat` をダブルクリックします。
2. 初回のみ `.venv` が作られ、必要ライブラリが自動導入されます。
3. 起動後、既定ブラウザで `http://127.0.0.1:8765` が開きます。
4. 終了するときはタスクトレイのSF6アイコンを右クリックし「終了」を選びます。黒い画面で `Ctrl+C` を押しても終了できます。

サーバーはローカル専用の `127.0.0.1` でのみ待ち受けます。同じネットワーク上の別PCからは接続できません。

### `start.bat` がすぐ閉じる場合

更新版の `start.bat` は、`py`、`python`、`python3` の順にPython 3.11以上を探します。見つからない場合やセットアップに失敗した場合は画面を閉じず、原因と対処を表示します。アプリ本体が異常終了した場合は、同じフォルダの `startup.log` に詳細を保存して画面にも表示します。

Pythonが見つからない場合は、[Python公式Windows版](https://www.python.org/downloads/windows/)から64-bit版をインストールし、インストール画面の `Add python.exe to PATH` を有効にしてください。

バッチファイルはWindowsの文字コード差による誤動作を避けるため、制御部分とメッセージをASCIIで記述し、起動時にUTF-8コードページを指定しています。Web画面、Pythonソース、SQLiteはUnicode対応のため、メモへ入力した日本語は文字化けしません。

手動で起動する場合：

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python app.py
```

## 使い方

想定フローは次の通りです。

1. 「新規作成」から戦略メモを書く
2. 応援スタイル・文字配置・テーマカラーを選び、プロンプト生成
3. 「コピーしてChatGPTを開く」を押す
4. ChatGPT Web版へ貼り付け、画像を生成してPCへ保存
5. 保存画像をファイル選択またはドラッグ＆ドロップで取り込む
6. プレビューを確認して「壁紙に設定」を押す

プロンプト設定は最後に生成した内容がSQLiteへ保存され、次回起動時に復元されます。

## サブディスプレイ常駐メモ（Phase 2）

Web画面の「サブディスプレイ常駐メモ」で、保存済み戦略メモを最大6件選択し、モニター・位置・サイズ・透明度・色などを設定して「設定を保存・反映」を押します。フリーテキストではなく元の戦略メモを参照するため、メモを更新して「内容更新」すると常駐表示にも反映されます。

- 枠なしウィンドウは、クリック透過OFFのときにドラッグして自由移動できます。移動後の座標は自動保存され、画面外へ飛び出さないよう選択中モニターの範囲内に制限されます。
- 右下の水色のリサイズハンドルをドラッグすると、幅と高さを変更できます。変更したサイズも自動保存されます。
- 「自由」を選ぶとWeb画面でX/Y座標も指定できます。負の座標にも対応します。
- 透明度は20～100%、文字サイズは10～72、サイズは幅240～1600・高さ140～1200です。
- 「Windows起動時に自動起動」は、ユーザーのスタートアップフォルダへ `SF6StrategyBoard.cmd` を登録します。OFFにすると登録ファイルを削除します。管理者権限は不要です。
- 自動起動時はブラウザを開かず常駐します。タスクトレイの「メイン画面を開く」から編集画面を開けます。

初期ホットキー：

| 操作 | ホットキー |
|---|---|
| 表示／非表示 | `Ctrl + Alt + M` |
| 常に最前面切替 | `Ctrl + Alt + T` |
| クリック透過切替 | `Ctrl + Alt + C` |
| 編集画面を開く | `Ctrl + Alt + E` |

ホットキーにはWindowsの `RegisterHotKey` を使用し、管理者権限は不要です。他アプリが同じキーを占有している場合、そのキーだけ登録できないことがあります。

### クリック透過の安全対策

クリック透過をONにすると、メモをマウスで直接操作できません。解除経路は常に3つあります。

1. `Ctrl + Alt + C` を押す
2. タスクトレイのSF6アイコンから「クリック透過切替」を選ぶ
3. Web画面の「クリック透過を解除」を押す

### タスクトレイ

タスクトレイから、メイン画面を開く、表示、非表示、最前面切替、クリック透過切替、内容更新、自動起動切替、アプリ終了を操作できます。アイコンが見えない場合はWindowsの「隠れているインジケーター」を確認してください。

## 復習・自動選出（Phase 3）

各メモに習熟度、次回復習日、成功・失敗回数、タグ、お気に入り、アーカイブ、学習状態を保存できます。既存のPhase 1/2データベースは、初回起動時に不足列とテーブルだけを追加する簡易マイグレーションで更新されます。既存メモは削除されません。

### 復習の流れ

1. 画面上部の「今日の復習」で期限を迎えたメモを確認します。
2. 「忘れていた」「少し迷った」「問題なくできた」「実戦で成功した」から結果を選びます。
3. 「記録」を押すと習熟度、成功・失敗回数、次回復習日が更新されます。
4. 必要な項目を壁紙候補または常駐メモ候補へ追加できます。

復習間隔は、履歴に応じて基本の `1 → 3 → 7 → 14 → 30日` を進みます。

- 忘れていた：習熟度を1段階下げ、翌日に再確認
- 少し迷った：習熟度を維持し、標準間隔の約半分
- 問題なくできた：習熟度を1段階上げ、標準間隔
- 実戦で成功した：習熟度を1段階上げ、標準間隔の2倍（最大60日）

### 自動選出

自動選出は、復習期限、低い習熟度、高い優先度、失敗と成功の差、お気に入りを点数化し、アーカイブ以外から選びます。壁紙候補は最大5件、常駐メモ候補は最大3件です。「候補から壁紙プロンプト生成」で複数課題をまとめたChatGPT用プロンプトを作成できます。

### テンプレートと検索

コンボ、セットプレイ、キャラ対策、実戦課題のテンプレートを用意しています。メモ編集欄のテンプレートボタンから新規メモへ適用できます。一覧は全文、キャラクター、カテゴリ、優先度、習熟度、タグ、お気に入り、アーカイブ状態で絞り込めます。

### 画像・壁紙履歴

取り込んだ画像には、取り込み時に編集中だったメモが紐付きます。画像履歴から再利用でき、壁紙履歴から過去の壁紙を再設定またはお気に入り登録できます。元画像ファイルを手動削除した場合は、履歴のプレビューや再設定は利用できません。

### バックアップと復元

画面下部の「バックアップをダウンロード」で、SQLite DBと読みやすい `settings.json` をZIPへ書き出します。メモ、復習履歴、テンプレート、設定、画像・壁紙の管理情報が含まれます。画像ファイル本体は容量を抑えるため含みません。完全バックアップには、アプリ停止後に `data/wallpapers` も別途コピーしてください。

復元は「ZIPから復元」でバックアップZIPを選択します。現在のDBが置き換わるため、必要なら先に現在のバックアップをダウンロードしてください。復元後は画面が自動再読み込みされます。

## 画像と壁紙

PNG/JPG/JPEG/WebPに対応します。取り込んだ原本は `data/wallpapers/originals` に保存し、Pillowで検証・PNG変換した壁紙用画像は `data/wallpapers/current` に保存します。透過画像の背景はダーク色で合成します。

壁紙設定にはWindows API `SystemParametersInfoW` を使用します。新しい壁紙を設定する直前に、Windowsが示す現在の壁紙ファイルを `data/wallpapers/history` へコピーします。「前の壁紙に戻す」は直近のバックアップを設定し直します。バックアップ元が取得できない、ファイルにアクセスできない等の場合は画面に理由を表示します。復元は1段階です。

メモ、設定、画像の管理情報は `data/app.db` に保存されます。アプリをバックアップする場合は、停止後に `data` フォルダ全体をコピーしてください。

## 動作確認・テスト

起動後、次を順番に確認できます。

- メモを新規保存し、一覧から選択して編集保存し、最後に削除する
- 技名・数字・矢印を含むメモからプロンプトを生成し、内容が保持されることを確認する
- JPGまたはWebPを取り込み、プレビューが表示されることを確認する
- `data/wallpapers/current` に同名IDのPNGが作成されることを確認する
- 「壁紙に設定」でWindows壁紙が変わることを確認する
- 続けて「前の壁紙に戻す」で直前の壁紙へ戻ることを確認する
- 常駐メモでサブディスプレイを選び、表示位置・透明度・最前面を確認する
- クリック透過をONにした後、ホットキー・トレイ・Webの各経路から解除できることを確認する
- メモをドラッグ移動して再起動し、位置が復元されることを確認する
- 期限が今日以前のメモで復習結果を記録し、次回復習日と習熟度が更新されることを確認する
- 自動選出の候補から壁紙プロンプトと常駐メモ本文を作成する
- 画像履歴から画像を再利用し、壁紙履歴から過去の壁紙を再設定する
- バックアップZIPをダウンロードし、`app.db` と `settings.json` が含まれることを確認する

自動テスト：

```powershell
.\.venv\Scripts\python.exe -m pytest -q
```

プロンプトの原文保持と、JPEGからPNGへの変換をテストします。Windows壁紙APIは実際のデスクトップを変更するため、自動テストには含めず上記の手動確認としています。

## 注意事項

- ChatGPTの自動操作やOpenAI API呼び出しは行いません。
- Windowsの企業ポリシー等で壁紙変更が禁止されている環境では設定できません。
- 一部の全画面ゲームはWindowsの最前面ウィンドウより前に描画されます。その場合はゲームを「ボーダーレスウィンドウ」にすると常駐メモを表示しやすくなります。
- モニターを抜き差しした場合はWeb画面を再読み込みし、表示先を選び直してください。
- `data` 内の画像やDBを手動削除する場合は、アプリを終了してから行ってください。
